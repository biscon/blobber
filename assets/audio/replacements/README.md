Place user-recorded or externally sourced replacement WAV files here. This directory
is never written by the generator. Map files through `../overrides.json`, as shown
in [the replacement guide](../README.md), and include source/author/license details
in each variant's `provenance` field.

Five selected model exports are retained here: dark B, radiant A, fire B,
thunder B and spiritual.loop A. `provenance.json` records their origins and hashes.
They are the base bank's only variants for those cues; the unused synth variants
were deleted. They can be replaced like any other sample. The model and its tools
have been removed; normal Csound regeneration preserves these WAVs.
