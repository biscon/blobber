# Sanctuary smithy painted pack

Generated by `tools/export_smithy.py` from the retained Sanctuary city material
master, city paving and joint-free timber grain. Ceiling texture is shared with
the inn. Runtime requires no Blender. Packed Blender and unlit GLB, texture sources
and triangle JSON are regenerated together; edit the exporter, not just the blend.
The [approved concept](../../../docs/mockups/smithy-v1/README.md) and
[interior design](../../../docs/smithy_interior_design.md) define the visual and
cell-reservation contracts. All props are decoration; the future NPC is absent.

From the repository root, use an owned staging run rather than writing exports
directly into the asset tree:

```sh
smithy_run=$(python3 tools/agent_artifacts.py create)
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 nice -n 15 ionice -c 3 timeout 240 \
  blender --background --factory-startup -noaudio -t 2 --python tools/export_smithy.py -- \
  --output-root "$smithy_run/assets" --report "$smithy_run/export.json"
# Inspect output and the report before promoting selected durable asset files:
cp -a "$smithy_run/assets/packs/sanctuary-smithy/." assets/packs/sanctuary-smithy/
nice -n 15 ionice -c 3 cmake --build --preset debug --target blobber -j 1
python3 tools/agent_artifacts.py clean "$smithy_run"
python3 tools/agent_artifacts.py clean "$smithy_run" --apply
```

The current pack has 11 models / 2,996 triangles and a 4096² atlas, retaining
256 texels per cell and 16-pixel gutters. Export asserts horizontal footprint
bounds and furniture height; no atlas shrinking occurs on capacity exhaustion.
World publication discovers the pack through the existing CMake dependency glob.

The 2026-11-07 review correction scales individual swords to 65% and the shield to
75% before UV packing. Sword guards rest on the existing upper rail; rack frames,
cell reservations and save identities are unchanged. Additional decoration is deferred.
