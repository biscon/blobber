# Early equipment artwork

These 31 project assets were generated with the built-in `image_gen.imagegen` tool. No CLI/API fallback was used. Each PNG retains its generated transparency; individual JSON files contain the exact final prompt and tool settings. The padded armor also records the existing quarterstaff style reference.

The intended style is detailed painted dungeon equipment, weathered brown leather and subdued steel, isolated on transparency, with restrained blue accents for +1 weapons. Runtime preparation fits each icon into a 256-pixel atlas tile without changing its aspect ratio.
