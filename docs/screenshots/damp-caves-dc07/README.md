# DC07 campaign review

Three 1920×1080 frames from the hidden game renderer on seed five accompany the [player walkthrough](../../dc07_campaign_descent_design.md#player-review).

| View | What to check |
| --- | --- |
| [Development starting floor](starting-floor.png) | Each destination shows its starting level and XP per character. The Seep begins at level two with 675 XP. |
| [Sanctuary waypoints](waypoints.png) | A party that reached the Vault can return to any of the six entrances. All destinations fit in the travel window. |
| [Vault victory](vault-victory.png) | The campaign result appears over the Vault with the selected saved character, Ida, still in the four-person party. |

The capture runner used the production catalog, an isolated character library and scripted in-game state. It shortened the final fight. Timing the hatch warnings and judging the fight by playing it are part of player review.
