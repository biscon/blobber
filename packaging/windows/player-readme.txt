Stone & Shadow — Windows 11 x64 review build

Verify the adjacent .sha256 with PowerShell Get-FileHash -Algorithm SHA256.
Extract the ENTIRE ZIP, then launch blobber.exe. Keep assets and notices beside it.
No compiler, SDK, administrator install or VC redistributable is required by the
static-runtime build. A working OpenGL 3.3 graphics driver is required.

User files live in %LOCALAPPDATA%\blobber: campaign.json, characters.json,
scenarios, settings.json and music state. Back up any existing user data first.
Installation content may remain read-only. Saves require matching content/formats.

Review menu/text/graphics, sound/music/dialogue, New Campaign, town/inn/dungeon,
Save and Main Menu, then exit and restart Continue. Try a path containing spaces
and non-ASCII characters, launching from another working directory without --assets.
Hosted software OpenGL checks do not establish real GPU behavior or audio playback.

This is a manually requested review artifact, not a signed installer or a public
GitHub Release. Third-party notices are in notices/. Existing attribution gaps
are recorded in the distribution handoff; no new project license is granted here.
